NAGYMIZDÓI LOVASUDVAR – ANIMÁLT, TÖBBOLDALAS WEBOLDAL

Oldalanként külön HTML, CSS és JS:
- index.html / index.css / index.js
- bemutatkozas.html / bemutatkozas.css / bemutatkozas.js
- szolgaltatasok.html / szolgaltatasok.css / szolgaltatasok.js
- galeria.html / galeria.css / galeria.js
- kapcsolat.html / kapcsolat.css / kapcsolat.js

Funkciók:
- animált oldalbetöltő
- lassú, mozgó hero háttér
- animált főcím belépés
- scroll reveal animációk
- parallax jellegű háttérmozgás desktopon
- sticky, üveghatású fejléc
- animált mobilmenü
- hover mozgások a kártyákon és gombokon
- galéria lightbox
- reduced-motion beállítás tiszteletben tartása

Telepítés:
A fájlokat tartsd egy mappában, és nyisd meg az index.html-t.
GitHub Pages-re közvetlenül feltölthető, nincs build folyamat.

Fontos:
A fotók jelenleg illusztratív Unsplash képek. Cseréld a lovasudvar saját képeire.
A telefonszám, e-mail, cím és a szolgáltatások élesítés előtt ellenőrizendők.
A Google Fonts és Unsplash képek külső internetes szolgáltatásokat használnak.
